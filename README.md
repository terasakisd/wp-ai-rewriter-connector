# WP AIリライター コネクタ

WP AIリライター（社内ツール）との接続用の軽量プラグインです。
シート連携のフル版（sheets-to-wp-posts）から、WP AIリライターに必要な機能だけを抜き出したものです。

## 提供する機能

1. **Basic認証環境での認証橋渡し** — サーバーのアクセス制限とアプリケーションパスワードを両立（`X-WP-App-Auth` ヘッダー対応）。Basic認証下で無効化されるアプリケーションパスワード発行フォームも有効化
2. **サイトプレビュー** — リライト結果を実テーマの見た目で確認できる一時プレビュー（トークン付き・1時間で失効・noindex・記事本体は無傷。下書き記事にも対応）
3. **メタディスクリプション連携** — REST経由での保存に対応し、Yoast / Rank Math / SEOPress が有効ならそのフィールドへ自動コピー。SEOプラグインが無ければ `<meta name="description">` を出力

## 使い分け

| サイトの運用 | 入れるプラグイン |
|---|---|
| WP AIリライターだけ使う | **このコネクタのみ**（軽量） |
| スプレッドシート連携も使う | sheets-to-wp-posts（フル版・コネクタの機能を全て含む） |

両方入れても衝突しません（フル版が有効な場合、コネクタは自動で無効になります）。

## インストール

zipをWP管理画面からアップロードして有効化するだけです。設定画面はありません。
